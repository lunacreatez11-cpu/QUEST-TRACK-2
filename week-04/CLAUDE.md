# week-04 · Drop 에셋으로 만드는 내 게임

## 이번 주
- 주제: **Drop 에셋으로 만드는 내 게임**
- 목표: **남이 만든 그림과 소리를 제자리에 넣고, 잘 되는지 확인하기**

## 이번 주에 만드는 게임 (두 개)
- 연습 게임: `week-04/practice/index.html`
- 내 게임: `week-04/index.html`

## 이번 주 규칙
- 게임은 HTML 과 JavaScript 로 만들고, index.html 을 두 번 눌러도 열리게 한다.
- 그림과 소리는 그 게임 폴더 안의 assets 폴더에 둔다.
  (연습 게임 → `week-04/practice/assets/`, 내 게임 → `week-04/assets/`)
- 출처 표기가 필요한 에셋은 그 게임 폴더의 CREDITS.md 에 적는다.
  (연습 게임 → `week-04/practice/CREDITS.md`, 내 게임 → `week-04/CREDITS.md`)
- 답은 한국어로 한다.
- 이번 주 작업은 week-04 폴더 안에서만 한다.
- 나머지는 맨 위 폴더의 CLAUDE.md 를 따른다.
