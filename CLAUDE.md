# QUEST TRACK 2 workshop

## My computer
- Windows, PowerShell. Git, Node.js and Python are installed.
- If you need to install a new program or package, ask me first.

## Folder rules
- This folder is my workshop. Don't read or change any files outside it.
- There's a folder for each week, week-01 to week-11. Do each week's work only in that week's folder.
- If a week folder's CLAUDE.md is different from this one, follow the week's one.
- Always ask me before you delete or rename a file.

## Saving
- Only push to GitHub when I ask you to.
- The default branch is main. Don't make other branches without my permission.

## Things to keep
- This is a public repository. Anyone can see it.
- Don't put phone numbers, addresses or school names in web pages or files.
- Don't write passwords or API keys in files.

## Progress log (you write it)
- progress.md is your log. I don't edit it.
- When class ends (when I say "done for today" or we make the last commit), sum up today's chat and work, add it to the bottom of progress.md in the format below, and commit.
- Only write facts you saw and heard. Don't exaggerate praise or criticism. For each section, add a short note in brackets on what it's based on (a request I made, how many fixes, where I got stuck).
- Don't write phone numbers, addresses, schools, real names or stories about other people. This repo is public.
- When a new week starts, read progress.md first and start by talking about "Try next class" from the last entry.

  ## week-01 · (date)
  ### What I made
  - Name · one-line description · how finished (done / almost / just started)
  ### How I worked
  - How many requests I sent, how my first and last requests were different
  - What I did when stuck (asked again / pasted the error and asked / stopped)
  ### Style
  - Work style you noticed (e.g. builds it big first then polishes, checks small parts one by one)
  ### Did well
  ### Could be better
  - Write it as one thing I can practice right away next time
  ### Better than last time
  - First week: "Nothing to compare yet"
  ### New things I learned
  ### Got stuck → how I fixed it
  ### Try next class
  - One or two things you suggest after reading today's log
